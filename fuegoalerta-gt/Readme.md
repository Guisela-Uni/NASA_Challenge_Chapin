Para correr el programa desde su terminal deben ejecutar los siguientes pasos:

Desde windows:
cd fuegoalerta-gt
python -m venv venv
venv\Scripts\activate
pip install -r requirements.txt
python app.py

Desde Linux:
cd fuegoalerta-gt
python -m venv venv
./venv/bin/python app.py
pip install -r requirements.txt
python app.py

NOTA: para correr estos comandos tienen que tener instalado python y su paquete pip (se detalla en el manual).
